How to Connect Real Google Sheets (5-Minute Step-by-Step Guide)
Google Cloud Console Setup
  1. Visit Google Cloud Console and create a free project (e.g. student-progression-dbms).
  2. Navigate to APIs & Services > Library. Search for and enable:
    • Google Sheets API
    • Google Drive API
  3. Go to APIs & Services > Credentials. Click Create Credentials > Service Account.
  4. Enter any service account name (e.g. dbms-sync-bot) and click Done.
  5. Click on the newly created service account > Keys tab > Add Key > Create new key > Choose JSON.
  6. Save the downloaded JSON file as service_account.json in the project directory: C:\Users\Gaurishankar Yadav\Downloads\DBMS_Student_Progression_Project\service_account.json.
Spreadsheet Setup & Sharing
  1. Open Google Sheets and create a blank spreadsheet named Student Academic Progression.
  2. Extract the spreadsheet ID from your browser address bar:
    https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit
  3. Open the downloaded service_account.json file, find the "client_email" field (e.g. dbms-sync-bot@your-project.iam.gserviceaccount.com).
  4. In your Google Sheet, click the green Share button at the top right, paste the service account email, set the role to Editor, and click Send.
  5. Set the environment variable in your terminal:
    $env:GOOGLE_SHEET_ID="YOUR_SPREADSHEET_ID" (PowerShell) or put it in .env.
  6. Click the Trigger Sync Now button above! The system will automatically generate a formatted tab named Progression.
